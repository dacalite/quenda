# Quenda

> **Prototipo con datos simulados.** Non hai servidor: os datos gárdanse no navegador e restáuranse ao reiniciar a demo.

Proposta para o **I Certame GOBTEC de Software Libre**: unha plataforma de xestión e reserva de instalacións deportivas municipais para concellos e deputacións, deseñada con accesibilidade WCAG 2.1 AA desde o primeiro compoñente.

Estado: en desenvolvemento.

## Executalo

Precisa Node.js 22 ou superior.

```sh
npm ci
npm run dev
```

Outros comandos: `npm test`, `npm run e2e`, `npm run lint` e `npm run build`.
